# 🤖 Единая инструкция по запуску робота Spark (Соревнования / Тесты)

> **Назначение:** Быстрый запуск робота через **Единый пульт управления (`dashboard.sh`)** в один клик без кучи окон.  
> **Робот:** NXROBO Spark (Ubuntu 20.04 LTS, ROS Noetic)  
> **SSH доступ:** `ssh spark@10.24.170.0` (пароль: `simple2026`)

---

## 🚀 1. Быстрый запуск в 1 клик с компьютера (Windows)

Больше не нужно вбивать длинные команды и помнить IP-адрес:

### Вариант А (Самый простой — Двойной клик на Windows):
Просто дважды кликни мышкой по файлу **`START_ROBOT.bat`** в папке `D:\ROS competition`!
- Он покажет текущий сохраненный IP (`10.24.170.0`).
- Нажми **Enter** (или введи новый IP, если робот получил другой адрес от Wi-Fi).
- Скрипт мгновенно откроет красивый терминал с пультом управления!
- При подключении все системы (ROS master, база, камера, лидар, рука, детектор и `runtask`) **запускаются автоматически**, если ещё не запущены.
- Все процессы теперь отвязаны через `setsid`: закрытие терминала, SSH или MobaXterm **больше не убивает робота** — он продолжает работать в фоне.

### Вариант Б (Через PowerShell):
```powershell
.\connect.ps1
```
*(Если нужно обновить IP: `.\connect.ps1 10.24.170.15`)*

### Шаг обновления кода на роботе (перед соревнованиями):
В PowerShell на компьютере:
```powershell
.\upload.ps1
```
```powershell
powershell -ExecutionPolicy Bypass -File "D:\ROS competition\upload.ps1"
```
*(Скрипт автоматически скопирует обновленный `runtask.py`, `dashboard.sh`, `start_system.sh`, `keypatched2v.py` и `arm_ik.py` на робота).*

## 🕹️ 2. Меню пульта управления на роботе

В открывшемся меню доступны горячие клавиши:

| Клавиша | Действие | Что происходит |
|:---:|---|---|
| **`1`** | **Запустить все системы** | Фоновый запуск: база, камера RealSense D435, лидар, манипулятор uArm, веб-стрим, детектор YOLO и мозги `runtask.py`. |
| **`2`** | **Тест захвата кубика** | Отправляет команду `/grasp 1`: робот собирает 10 кадров с камеры, усредняет координаты кубика, включает помпу и поднимает его. |
| **`3`** | **Тест отпускания кубика** | Отправляет команду `/grasp 0`: помпа выключается, кубик отпускается, рука возвращается в готовность. |
| **`4`** | **Плавный ручной джойстик** | Запускает `keypatched2v.py` (управление базой на WASD, рукой на 8/2/7/9/4/6, помпой на Enter, аварийный стоп на Space). |
| **`5`** | **Смотреть живой лог runtask** | Показывает в реальном времени, что думает робот. *(Для выхода обратно в меню нажать клавишу **`q`**)*. |
| **`6`** | **Остановить все системы** | Чисто гасит все процессы и освобождает порты. |
| **`0`** | **Выход в консоль bash** | Выход из меню в обычный терминал. |

## 🛠️ 4. Как обновить код с компьютера на робота

Если на ПК отредактированы файлы, они отправляются одной командой в PowerShell:

```powershell
# Обновить файл логики runtask:
scp "D:\ROS competition\spark_humble_ws\codes\runtask.py" spark@10.24.170.0:/home/spark/spark_noetic/src/3rd_app/auto_match_25/auto_match/nodes/runtask.py

# Обновить скрипты управления:
scp "D:\ROS competition\spark_humble_ws\codes\start_system.sh" "D:\ROS competition\spark_humble_ws\codes\stop_system.sh" "D:\ROS competition\spark_humble_ws\codes\dashboard.sh" spark@10.24.170.0:/home/spark/codes/
```

## 🚑 5. Устранение частых проблем

### Если колёса базы заблокированы:
Проверь датчики бампера:
```bash
rostopic echo -n 1 /spark_base/sensor
```
Если `ir_bumper_right: True` при пустом пространстве — выключи робота тумблером питания на 5 секунд и включи снова.

### Если не двигается манипулятор:
Проверь порт USB манипулятора:
```bash
ls /dev/ttyACM*
sudo chmod 666 /dev/ttyACM*
```

### Расположение логов:
Все логи пишутся в папку `~/logs/`:
* `~/logs/runtask.log` — логи принятия решений и захвата
* `~/logs/detect.log` — логи детектора объектов
* `~/logs/base.log` — логи шасси и камеры
* `~/logs/arm.log` — логи руки
