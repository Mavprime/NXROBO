# Project Context & Developer Handoff: NXROBO Spark Autonomous Competition

> **Назначение файла:** Единый источник актуального контекста проекта для разработчиков, участников команды и ИИ-ассистентов.  
> **Дата обновления:** 18 ноября 2026 г.  
> **Текущий статус:** Фазы 0 и 1 завершены на 100% (аппаратный комплекс, калибровка захвата и зрение полностью верифицированы на реальном роботе). Проект подготовлен к картографированию арены (Фаза 2) и боевым прогонам FSM (Фаза 3).

## 1. Основные сведения о проекте и регламенте

- **GitHub репозиторий проекта:** `https://github.com/Mavprime/NXROBO` (командный репозиторий)
- **Цель:** Подготовка автономного робота **NXROBO Spark** к дисциплине **«Полный автоном»** (自动任务赛 / «Д夺宝奇兵自动赛» — 10 минут, 10 кубиков).
- **Правило первого кубика:** **Торт со 2-го яруса центральной тумбы ОБЯЗАН быть доставлен в Зону A ПЕРВЫМ**. Только после этого разрешается сбор и доставка остальных 9 кубиков (Мишки, Часы, Бананы) в Зоны B, C, D согласно доске классификации.
- **Очки:**
  - Красный квадрат приёмки (0.45 × 0.45 м): 1-й этаж = 2 б, 2-й этаж = 4 б, 3-й этаж = 7 б (формула: $N + 2^{N-1}$).
  - Обычная зона транспортировки: 1-й этаж = 1 б, 2-й этаж = 2 б, 3-й этаж = 4 б.
  - Старт из базы: +1 б.
- **Ограничения:** Полный запрет на вмешательство оператора во время заезда. Перезапуск возможен не более 3 раз до отрыва первого кубика от земли.

## 4. Архитектура программного обеспечения

```
[Windows ПК оператора]
  ├── START_ROBOT.bat        --> 1-клик запуск, автоподстановка IP, подключение к dashboard.sh
  ├── upload.ps1             --> Синхронизация кода на робота (SCP)
  ├── connect.ps1            --> Быстрый вход по SSH
  └── robot_ip.txt           --> Текущий IP робота в локальной сети
          │
      (SSH / SCP)
          ▼
[Робот NXROBO Spark (Ubuntu 20.04)]
  ├── ~/codes/dashboard.sh   --> Интерактивное меню оператора (1-7)
  ├── ~/codes/start_system.sh--> Фоновый запуск стека ROS (bringup, swiftpro, auto_match)
  ├── ~/codes/stop_system.sh --> Мягкая и аварийная остановка всех процессов
  ├── ~/codes/keypatched2v.py--> Плавное телеуправление (WASD, самоподключение путей ROS)
  ├── ~/codes/camera_stream.py-> MJPEG-стрим камеры на порт 8080
  ├── ~/codes/arm_ik.py      --> Геометрическая модель и проверка reachability
  └── ~/codes/runtask.py     --> Конечный автомат соревнований (FSM)
```

## 5. Инструкции по запуску для оператора

### Основной запуск (1-клик):
1. Нажмите дважды на **`START_ROBOT.bat`** на ПК оператора.
2. При запросе подтвердите IP (нажмите `Enter` для использования IP из `robot_ip.txt` или введите новый).
3. В открывшемся интерактивном меню на роботе выберите:
   - **`1`** — Запуск всех подсистем робота (шасси, камера, лидар, манипулятор, зрение).
   - **`2`** — Тест захвата кубика на месте (проверка помпы и руки).
   - **`3`** — Тест отпускания кубика.
   - **`4`** — Плавное ручное управление с клавиатуры (`keypatched2v.py`).
   - **`5`** — Просмотр живого лога соревнований (`runtask.log`, выход по клавише `q`).
   - **`6`** — Полная остановка систем.
   - **`7`** — Выход из меню.

### Автономный боевой запуск (после развертывания арены):
```bash
# Старт матча (публикация флага готовности):
rostopic pub /task_start_flag std_msgs/String "1"

# Экстренное прерывание матча:
rostopic pub /task_start_flag std_msgs/String "0"
```
