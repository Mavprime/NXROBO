Spark Robot - Quick Commands

Run these after every boot. source only loads the ROS environment; the server terminal starts the ROS master and the hardware drivers.

0. Copy your codes/ folder to the robot (from your PC)

rsync -av "<local-dir>/" <user>@<robot-ip>:<remote-dir>/

Run this on your PC, not inside the robot's shell. Example for the usual layout (local repo → ~/codes on the robot):

rsync -av "/home/mav/Documents/Extra/ROS Comp/codes/" spark@<robot-ip>:~/codes/

The trailing slash on the source copies the folder's contents; without it you get a nested codes/codes. The default SSH password on the Spark boards is 123456.

If rsync is not available, use scp instead:

scp -r "<local-dir>" <user>@<robot-ip>:<remote-dir>

1. Server terminal (keep it open)

source ~/spark_noetic/devel/setup.bash
roslaunch ~/codes/server.launch

Starts the ROS master, the base driver, and the arm driver. It does not start the camera or the lidar.

2. Any script terminal

source ~/spark_noetic/devel/setup.bash
python3 ~/codes/<code>.py

Replace <code> with the script name. Open as many script terminals as needed; they all connect to the same ROS master.

Keep the server terminal open. Closing it stops the master and all drivers. To keep it running after the terminal closes:

setsid nohup roslaunch ~/codes/server.launch > ~/server.log 2>&1 < /dev/null &

Stop it with pkill -f "roslaunch.*server.launch".

3. Minimal alternative (no server.launch)

# Terminal 1 - ROS master
source ~/spark_noetic/devel/setup.bash
roscore

# Terminal 2 - base driver
source ~/spark_noetic/devel/setup.bash
rosrun spark_base spark_base_node /dev/sparkBase __name:=spark_base_server

# Terminal 3 - arm driver
source ~/spark_noetic/devel/setup.bash
rosrun swiftpro swiftpro_write_node

# Terminal 4 - any script
source ~/spark_noetic/devel/setup.bash
python3 ~/codes/<code>.py

4. Camera / full setup

If a script needs the camera or lidar, use these launches instead of server.launch:

# Terminal 1
source ~/spark_noetic/devel/setup.bash
roslaunch spark_bringup driver_bringup.launch camera_type_tel:=d435 lidar_type_tel:=ydlidar_g6

# Terminal 2
source ~/spark_noetic/devel/setup.bash
roslaunch swiftpro pro_control_nomoveit.launch

# Terminal 3
source ~/spark_noetic/devel/setup.bash
python3 ~/codes/<code>.py

5. Before you run anything

ls -l /dev/sparkBase      # base serial
ls -l /dev/ttyACM*        # arm serial (expect /dev/ttyACM0)

If the arm device is missing, reconnect or power it. Without /dev/ttyACM0 the arm driver reports Unable to open port.

6. Verify

rosnode list
rostopic hz /SwiftproState_topic      # arm: expect about 20 Hz
rostopic info /cmd_vel                # base: expect a subscriber

If you see Unable to register with master, the server terminal is not running.
