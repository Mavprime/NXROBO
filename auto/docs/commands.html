Spark Robot - Commands

Two terminals on the robot: T1 starts ROS and the hardware drivers, T2 runs ~/auto/codes/body.py. Keep T1 open while T2 is running.

T1 - server (keep it open)

source ~/spark_noetic/devel/setup.bash
roslaunch ~/auto/codes/server.launch

Starts the ROS master, the base driver and the uArm. Closing this terminal stops the master and every driver.

T2 - body.py

source ~/spark_noetic/devel/setup.bash
python3 ~/auto/codes/body.py

Base-only keyboard teleop: w/s drive forward/back, a/d turn. Ctrl+C stops the base; the server in T1 keeps running.

Auto match (commands from the manual)

These are the commands in CN spark configure sections 2-3. They use the vendor's auto_match package, not ~/auto/codes.

Hand-eye calibration

cd ~/spark_noetic/
./onekey.sh
# choose 8, then uArm, then Enter
# rotate the camera until the green pattern lines up with the red square, Enter
# result is saved to ~/thefile.txt

Install the package

sudo unzip auto_match_25.zip -d /home/spark/spark_noetic/src/3rd_app/
# password: spark
cd ~/spark_noetic
catkin_make

Make the nodes executable

cd ~/spark_noetic/src/3rd_app/auto_match_25/auto_match/nodes
sudo chmod +x *.py
cd ../scripts
sudo chmod +x *.sh

Build the map and record waypoints

cd ~/spark_noetic
source devel/setup.bash
roslaunch auto_match auto_match.launch open_guide:=true

Drive with WASD; Enter records the current point. Record every point before saving - the script stores Classification_area, Collection_B, Sorting_N and Sorting_W in config/mark_map.pkl and then saves the map.

Run the task

cd ~/spark_noetic
source devel/setup.bash
roslaunch auto_match auto_match.launch
# second terminal
rostopic pub /task_start_flag std_msgs/String "data: 'true'" -1 >/dev/null

The Python excerpts the manual walks through are saved next to this file: mark_move.py (waypoints and navigation, section 3.2), runtask.py (task flow, navigation timeout, grasp, 3.3-3.6) and detect_ros.py (TF SSD-MobileNet detector, 3.7). They are partial transcriptions, not complete nodes.
