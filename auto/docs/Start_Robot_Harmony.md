# Полная инструкция по работе с роботом Spark-HM (HarmonyOS)

Данное руководство содержит все шаги: от включения и поиска IP до загрузки своего кода, запуска драйверов и управления манипулятором.

  `D:\NXROBO\spark_humble_ws\codes\` (`keypatched2v.py`, `keypatched.py` и др.)

  `D:\NXROBO\spark_humble_ws\M-Robots 半自动赛资料\说明文档\`

## ⚡ Важное правило перед стартом: Провод USB Type-C

1. Провод USB Type-C от компьютера к роботу нужен **ТОЛЬКО** для того, чтобы узнать IP-адрес робота при первом включении.
2. Робот питается от **собственного аккумулятора**, а связь держит по **Wi-Fi**.
3. **Перед запуском движения ОБЯЗАТЕЛЬНО отсоединяйте USB-кабель от ПК**, иначе робот намотает провод на колеса или сдернет ноутбук со стола!

## 1. Как узнать IP-адрес робота

Компьютер и робот должны быть подключены к **одной и той же Wi-Fi сети** (или общей точке доступа с телефона/роутера).

### Способ А. Через USB-кабель и утилиту `hdc` (Быстрый)
1. Подключите провод USB Type-C от ноутбука к порту **USB-OTG / Host** на главной плате робота.
2. На ноутбуке откройте PowerShell и выполните:
   ```powershell
   cd "D:\NXROBO\spark_humble_ws\M-Robots 半自动赛资料\Tools"
   .\hdc.exe shell ifconfig
   ```
3. Найдите блок интерфейса **`wlan0`** и строчку `inet addr: 10.x.x.x` (или `192.168.x.x`). Запомните этот IP.
4. **Вытащите кабель USB Type-C.**

### Способ Б. Через экран робота
Если к роботу подключен дисплей:
* Зайдите в **Настройки (Settings) → Wi-Fi**, нажмите на вашу сеть и посмотрите назначенный IP-адрес.

## 2. Подключение к роботу через MobaXterm

1. Запустите `MobaXterm.exe`.
2. Нажмите кнопку **Session** (в левом верхнем углу) → выберите **SSH**.
3. Заполните параметры:
   * **Remote host**: введите IP робота (например, `10.24.88.146`)
   * Поставьте галочку **Specify username** и введите: `root`
   * **Port**: `22`
4. Нажмите **OK**.
5. При запросе пароля в терминале введите:
   * **Пароль**: `123456` *(символы при вводе скрыты — введите цифры и нажмите Enter)*.

---

## 3. Запуск робота («мозгов» и драйверов) — Вкладка №1

Чтобы заработали моторы, лидар, камера RealSense и манипулятор, необходимо запустить главный процесс:

1. В открытой сессии робота введите:
   ```bash
   cd /data/local/release
   ./onekey.sh
   ```
2. Появится нумерованное меню:
   * Введите **`11`** и нажмите **Enter**.
   * Если попросит подтверждение — нажмите **Enter** еще раз.
3. Побегут логи инициализации оборудования: включится лазерный сканер, запустится сервис камеры, поднимется VNC.
4. ⚠️ **Эту вкладку НЕ ЗАКРЫВАЙТЕ!** Она должна оставаться активной на протяжении всей работы робота.

*(Альтернативный запуск без меню: `run roslaunch semi_auto_match_24 semi_auto.launch`)*.

## 4. Как загружать и редактировать файлы с кодом на роботе

Основная папка для исполняемых скриптов на роботе:
`/data/local/release/usr/lib/semi_auto_match_24/`

### Вариант 1. Редактирование прямо на роботе через MobaXterm (Самый удобный)
Вам не нужно каждый раз копировать файлы туда-обратно:
1. В MobaXterm слева в панели проводника (SFTP) перейдите по папкам:
   `/data/local/release/usr/lib/semi_auto_match_24/`
2. Найдите нужный `.py` файл (например, `keypatched2v.py`).
3. Нажмите по нему правой кнопкой мыши → **Open with default text editor** (или дважды кликните).
4. Меняйте код и нажимайте **Ctrl + S** (Сохранить).
   *Файл моментально обновится прямо на роботе!*

### Вариант 2. Загрузка нового файла с компьютера
1. В левой панели MobaXterm откройте папку:
   `/data/local/release/usr/lib/semi_auto_match_24/`
2. Перетащите мышкой файл (например, `keypatched2v.py` из `D:\NXROBO\spark_humble_ws\codes\`) из Проводника Windows в окно MobaXterm.
3. В терминале робота обязательно **дайте файлу права на запуск**:
   ```bash
   chmod +x /data/local/release/usr/lib/semi_auto_match_24/keypatched2v.py
   ```

## 5. Запуск скрипта управления — Вкладка №2

Для управления роботом нужно отдельное окно терминала:

1. В левой колонке MobaXterm дважды кликните по вашей сохраненной сессии `10.24.88.146 (root)`, чтобы открыть **вторую параллельную вкладку**.
2. Запустите ваш скрипт:
   ```bash
   run python3 /data/local/release/usr/lib/semi_auto_match_24/keypatched2v.py
   ```
   *(Или стандартный соревновательный скрипт: `run rosrun semi_auto_match_24 teleop.py`)*.

### Горячие клавиши управления (`keypatched2v.py`):
* **Шасси**:
  * `W` / `S` — вперед / назад
  * `A` / `D` — поворот влево / вправо
  * `Q` / `E` — плавная дуга вперед-влево / вперед-вправо
  * `Space` (Пробел) — Экстренный стоп базы и руки
  * `f` / `Tab` — переключение скорости (FAST / SLOW)
* **Манипулятор (пошагово)**:
  * `8` / `2` — вверх / вниз (Z)
  * `7` / `9` — вперед / назад (X)
  * `4` / `6` — поворот руки влево / вправо (Y)
  * `1` / `3` — вращение насадки-захвата
* **Пресеты руки**:
  * `v` — безопасная высота парения (`Hover`, Z=30)
  * `t` — опустить к полу для взятия кубика (`Touch`, Z=-50)
  * `c` — поднять высоко для переноски (`Carry`, Z=90)
  * `0` — сброс в исходную позицию (`Home`)
* **Вакуумная помпа**:
  * `Enter` — включить / выключить присоску
* **Выход**:
  * `Ctrl + C` — остановка программы

## 6. Где настраивать параметры и скорости

### 1. Скорость движения базы и манипулятора
В файле `keypatched2v.py` (строки 51–64):
```python
SPEED_MODES = {
    "FAST": {
        "lin_speed": 0.20,     # линейная скорость базы (м/с)
        "ang_speed": 0.75,     # скорость поворота базы (рад/с)
        "arm_step": 15.0,      # шаг перемещения руки в мм (увеличьте для ускорения)
        "wrist_step": 12.0,    # шаг вращения захвата в градусах
    },
    "SLOW": {
        "lin_speed": 0.07,
        "ang_speed": 0.25,
        "arm_step": 4.0,       # точный плавный шаг руки
        "wrist_step": 5.0,
    },
}
```

### 2. Высота захвата манипулятора
В конфигурационном файле робота:
`/data/local/release/usr/share/semi_auto_match_24/config/grasp_heights.yaml`
* `z_up: 20` — высота наведения над объектом перед захватом
* `z_down: -45` — высота опускания присоски при захвате

### 3. Настройка распознавания цветов кубиков (HSV)
В конфигурационном файле робота:
`/data/local/release/usr/share/semi_auto_match_24/config/grasp_colors.yaml`

## 7. Графический интерфейс и RViz (VNC Viewer)

Когда запущено меню `./onekey.sh`, на роботе автоматически стартует VNC-сервер.

1. На ноутбуке запустите:
   `D:\NXROBO\spark_humble_ws\M-Robots 半自动赛资料\Tools\VNC_Viewer_v7.8.0.exe`
2. В строку подключения введите:
   `<IP_робота>:5900` (например, `10.24.88.146:5900`)
3. Нажмите **Connect**.
4. Откроется рабочий стол с RViz, где в реальном времени видны:
   * Карта и данные с лидара
   * 3D-модель робота
   * Изображение с камеры RealSense и маски распознавания объектов

## 8. Частые ошибки и их решение

| Ошибка / Симптом | Причина | Что делать |
| :--- | :--- | :--- |
| `Unable to register with master node` | Не запущен главный процесс ROS | Сначала запустите Вкладку №1 (`./onekey.sh` → пункт `11`), дождитесь старта и только потом запускайте телеоп. |
| `Couldn't find executable named ...` | Нет прав на выполнение или файл не в папке `lib` | Выполните: `chmod +x /data/local/release/usr/lib/semi_auto_match_24/<файл.py>` |
| Команда `run ...` пишет `command not found` | Вы ввели команду в локальной вкладке Windows | Обратите внимание на заголовок вкладки в MobaXterm: должна быть вкладка с IP робота, например `[10.24.88.146 (root)]`, а не `/home/mobaxterm`. |
| Робот дергается и застревает | Подключен кабель USB к ПК | Отключите провод USB Type-C от компьютера. Робот работает автономно по Wi-Fi. |
| Манипулятор не реагирует на пресеты | Координаты выходят за пределы рабочей зоны руки | Проверьте, чтобы координаты лежали в диапазоне: X: 90..320 мм, Y: -160..160 мм, Z: -85..180 мм. |
